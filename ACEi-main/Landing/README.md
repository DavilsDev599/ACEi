# Site Institucional da ACIAGI

Este é um projeto de site estático para a Associação Comercial e Empresarial de Iguatu (ACEI), desenvolvido com HTML, CSS e JavaScript.

## Visão Geral

O site apresenta informações institucionais, notícias, serviços e chamadas para ação (associação, guia comercial, área do associado), com design responsivo e foco em usabilidade.

## Estrutura de Arquivos

- `index.html`: Página principal com toda a estrutura semântica.
- `style.css`: Estilos completos, incluindo layout responsivo.
- `script.js`: Funcionalidades interativas (menu mobile, animações suaves).
- `README.md`: Este arquivo de documentação.

## Como Usar

1.  Baixe todos os arquivos e mantenha a mesma estrutura de pastas.
2.  Abra o arquivo `index.html` em qualquer navegador moderno.
3.  Para editar, modifique os arquivos de acordo com sua necessidade (textos, cores, links).

## Personalização

- **Cores**: As cores principais estão definidas no `style.css` (ex: `#0f3b5e`). Altere-as para ajustar à identidade visual desejada.
- **Textos**: Todo o conteúdo textual está no `index.html`, facilitando a edição.
- **Links**: Os botões e links de navegação apontam para `#` (placeholder). Substitua pelas URLs reais.

## Responsividade

O layout se adapta a diferentes tamanhos de tela (desktop, tablet, smartphone) usando media queries no CSS.

## Tecnologias Utilizadas

- HTML5
- CSS3 (com Flexbox e Grid)
- JavaScript (Vanilla JS)
- Google Fonts (Inter)
